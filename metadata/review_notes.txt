The app opens to the reserve menu with no mandatory onboarding. Select Start crossing for a random route. Tap to move forward, swipe or use the arrows; cars, missed logs and drifting beyond the river edge end the run. Pause resumes play or returns to the menu.

Select Daily expedition to collect three amber signs on grassy banks. The route is based on the device's local date. How to play includes optional practice; Journal shows locally stored results and discoveries. Practice does not count towards normal run statistics.

Sound can be toggled; gameplay uses haptic feedback. No device permissions, account, purchases, advertising, analytics or network gameplay are implemented. About supports configured HTTPS privacy and support links, but the bundled configuration is empty. Its Privacy page currently displays a policy-loading fallback because the requested filename differs from the bundled filename. The interface is English.
